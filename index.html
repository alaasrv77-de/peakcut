Connect your GitHub clipper

Peakcut runs the clipping on GitHub's free servers in your private repository. It needs an access key that only allows running that clipper and reading its results. The key stays in this browser.

  1. Open GitHub → New fine-grained token.
  2. Token name: Peakcut. Expiration: 1 year.
  3. Repository access: Only select repositories → peakcut-clips.
  4. Permissions → Repository: Actions: Read and write, Contents: Read-only.
  5. Click Generate token, copy it, and paste it below.
